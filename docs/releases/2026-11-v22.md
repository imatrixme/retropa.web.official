`9340b2b`，WebP 与模糊预览：

- 页眉 logo 换成 96 px 的 WebP（2.5 KB）。PNG 只留给 favicon、touch icon 和 manifest。
- `public/logo-wall/cores/` 的核心 logo 从 PNG 换成 WebP（`cwebp -q 90 -alpha_q 100`）。`emulator-catalog.ts` 的 `logoPath` 和 `sources.json` 的 `output` 随之改名。
- WebP 没有渐进式编码，“渐进式”改用模糊预览实现：
  - 构建时，每张 40 KB 以上的本地大图生成一张 24 px 的 WebP，套上 SVG 高斯模糊（约 0.5 KB），作为 `--lqip` 写进 `<img>` 的 style，随 HTML 一起到达。
  - head 脚本在图片 load 后移除 `data-lqip`，透明像素后面不会残留预览。没有 JavaScript 时不显示预览。
  - 首页有 15 张图带预览。Chrome 不把低熵图片当作 LCP 候选，所以预览不会提前或推迟 LCP。

`98ad7ee`，CSS 恢复外链：`astro.config.mjs` 改回 `inlineStylesheets: "auto"`，配置旁的注释写了原因。

## 测量

用的是 `scripts/seo/page-speed.mts`（Lighthouse 13.6），数值是 3 次的中位数。mobile 是模拟的慢速 4G 手机（150 ms RTT、1.6 Mbps、4 倍 CPU 降速）。测量机经香港出口访问美国主机，TTFB 偏高（约 0.6–1.0 s），绝对值比美国用户悲观，只适合同一网络下前后对比。

| 页面 | 形态 | 发布前 FCP / LCP / CLS | v22（CSS 内联） | v22.1（线上） |
| --- | --- | --- | --- | --- |
| `/` | mobile | 1.28 / 3.40 / 0.006 | 1.42 / 3.83 / 0.006 | 1.32 / 2.81 / 0.006 |
| `/` | desktop | 0.58 / 1.09 / 0 | 0.60 / 1.24 / 0 | 0.57 / 0.92 / 0 |
| `/mgba-core/` | mobile | 1.01 / 3.14 / 0 | 1.16 / 3.24 / 0 | 1.10 / 2.47 / 0 |
| `/mgba-core/` | desktop | 0.34 / 0.60 / 0.041 | 0.46 / 0.72 / 0.041 | 0.41 / 0.57 / 0.041 |
| `/ja/delta-skins/` | mobile | 0.99 / 0.99 / 0.020 | 1.15 / 1.15 / 0.001 | 1.07 / 1.07 / 0.001 |
| `/ja/delta-skins/` | desktop | 0.31 / 0.73 / 0.097 | 0.43 / 0.43 / 0.001 | 0.41 / 0.41 / 0.001 |

- CSS 全内联让每页 HTML 的传输量从约 33 KB 涨到约 59 KB（Cloudflare 对动态 HTML 的压缩比静态资源差），首图也被更晚发现，测过的页面 FCP 全部变慢。CSS 外链后，样式表可以并行下载，也能被缓存。
- v22.1 和发布前相比：
  - mobile LCP 在首页快 0.59 s，在 `/mgba-core/` 快 0.67 s。
  - desktop LCP 在三页上快 0.03–0.32 s。
  - `/ja/delta-skins/` 的 desktop CLS 从 0.097 降到 0.001。
  - mobile FCP 慢了 0.04–0.09 s，在这条线路 TTFB 的波动范围内。`/ja/delta-skins/` 的 mobile LCP 就是首段文字，所以也慢了 0.08 s。
- 报告目录都在 `~/.retropa/seo-reports/` 下：发布前 `page-speed-baseline-2026-11-01T13-21-02-588Z`，v22 `page-speed-after-v22-site-2026-11-01T13-58-17-092Z`，v22.1 `page-speed-after-2026-11-01T14-*`。

## 需要在 Cloudflare 面板做的事（没有 API 令牌，由用户操作）

- 给 `image.retropa.com` 加 Cache Rule。`/?url=` 形式的请求现在是 `DYNAMIC`：Cloudflare 按扩展名缓存，iOS App 的图片每次都要回源转码。PackHub 前端已改用 `/i.webp?url=`，边缘可以缓存。
- 关闭 Rocket Loader。站内已逐个脚本退出，但全局关闭更干净。
- HTML 边缘缓存：动态 HTML 每次回源，压缩也更差。如果开启，要对带 `Accept: text/markdown` 的请求绕过缓存，或者把 `Accept` 计入缓存键。
